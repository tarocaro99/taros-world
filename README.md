# taros-world

Portfolio of Caroline Chen (陈锦儿): UX, brand, print and motion.

Live at https://tarocaro99.github.io/taros-world/

A static site, no build step: `index.html` plus `assets/`. Open `index.html` in a browser or serve the folder locally.

Fonts are under the SIL Open Font License, and the stroke data for the name comes from hanzi-writer-data under the Arphic Public License. Licenses are in `assets/licenses/`.
